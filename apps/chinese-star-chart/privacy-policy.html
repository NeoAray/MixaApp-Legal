中华星盘

隐私政策

更新日期：2026年10月2日 · 生效日期：2026年10月2日

本政策适用于 Neilian（以下简称“开发者”或“我们”）提供的中华星盘 iOS / iPadOS App 及其小组件。联系邮箱：neoary@icloud.com。

一、处理信息的范围与目的

当前版本无需注册账户，未接入广告、广告追踪、第三方行为分析或开发者运营的数据服务器。星盘与历法计算在设备上进行。我们不会通过 App 将您的位置、观测选择或使用记录上传至开发者服务器，不出售个人信息。

  • 可选位置：当您选择当前位置并允许系统定位权限后，App 通过 Apple Core Location 获取经纬度、定位时间和精度等位置结果，用于计算当地星体方位、高度及当地时间。位置可能属于敏感个人信息；其使用仅为上述功能所需。您可选择预设观测地点，无需提供实际位置。
  • 城市识别：获得位置后，App 调用 Apple 的反向地理编码服务，将坐标转换为城市或地区名称。这项服务可能需要联网并向 Apple 发送坐标，由 Apple 按其隐私政策处理。星盘计算本身不依赖开发者服务器。
  • 本机设置与缓存：App 保存您选择的观测地点；为恢复位置和展示小组件，会在本机 App Group 共享容器中保存观测地点选项、经纬度、城市或显示名称、是否已有定位结果和定位时间。该容器供中华星盘主 App 与其小组件使用。
  • 运行诊断：App 可在系统本机日志中记录功能状态、计算耗时、交互性能、设备型号、系统版本及电源或温度状态等诊断信息。未接入开发者自动收集诊断日志的服务。Apple 的系统诊断与共享行为取决于您的系统设置及 Apple 政策。
  • 主动联系：您发送支持邮件时，我们会收到您的邮箱、邮件内容及您主动提供的附件，用于回应问题与处理隐私请求。请仅提供必要信息。

二、权限与您的选择

App 仅申请使用期间的定位权限，当前版本不申请后台持续定位，也不记录位置轨迹。若您已选择当前位置且此前已授权，再次打开 App 时可能重新请求一次位置。小组件读取本机共享缓存，不自行请求定位。

您可拒绝定位、在 App 中改用预设观测地点，或在系统“设置 → 隐私与安全性 → 定位服务 → 中华星盘”中撤回授权、关闭精确位置。拒绝或撤回授权不影响预设地点的星盘功能，但当前位置与城市识别可能不可用或不准确。

三、存储、保留与删除

观测设置与缓存保存在设备上，用于下次启动和小组件显示，并在新的观测选择或定位结果写入时更新。当前位置缓存保存的是最近一次使用的结果，未设自动到期删除。切换到预设地点会将供小组件使用的共享观测数据更新为该预设地点；撤回系统定位授权本身不会自动删除之前保存的数据。

当前版本没有独立的“清除数据”按钮。您可以通过系统删除 App（而非仅卸载 App 保留数据）以移除其本机数据；共享容器的清理由系统管理，系统备份的保留或恢复取决于您的备份设置。我们没有可供远程删除的位置副本。

支持邮件仅在回应、解决问题及必要的后续处理期间保留；若法律要求保留，按法定期限处理。您可通过联系邮箱请求删除不再必要的支持信息。我们采取合理措施保护收到的支持资料，仅为处理请求而访问。

四、第三方与政策网页

定位与城市识别由 Apple 系统服务提供，请参阅 Apple 隐私政策及 定位服务与隐私。App 下载、系统备份及系统诊断由相关 Apple 服务按其规则处理。

本政策及支持页面通过 GitHub Pages 托管。访问网页时，GitHub 会为安全目的记录访问者 IP 地址，并可能处理提供服务所需的技术信息；参阅 GitHub Pages 说明及 GitHub 隐私声明。我们未在中华星盘政策页面加入统计脚本、广告、第三方字体或追踪 Cookie。向我们发送邮件还会使用您选择的邮件服务。

五、您的个人信息权利

在适用法律规定的范围内，您可以了解、查阅、复制、更正或请求删除我们持有的个人信息，撤回同意，并请求解释处理规则。对于本机位置数据，您可通过上述系统设置和观测地点选择自行管理；对于您提供的支持邮件，请联系 neoary@icloud.com。我们会核实请求所需的最低限度信息，及时处理；无法满足的请求会说明原因。行使这些权利不会影响您使用不依赖相关信息的功能。

六、未成年人

未成年人应在监护人的指导下使用 App，建议选择预设观测地点。不满十四周岁用户使用涉及个人信息的功能或联系支持前，应取得监护人同意。监护人如发现孩子向我们提供了个人信息，可联系开发者请求协助删除。

七、政策更新与联系

功能或信息处理方式改变时，我们会更新本页并标明日期；对于需要重新征得同意的变更，会依法在相关处理发生前告知并取得所需同意。本政策不代替系统权限选择。如有隐私问题或投诉，请联系开发者 Neilian：neoary@icloud.com。
