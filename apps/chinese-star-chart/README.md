## 后续项目与兼容规则

其他 App 放在 apps/<稳定的英文项目标识>/，独立维护 index.html、privacy-policy.html、terms-of-use.html、support.html 及样式。目录标识一旦用于商店或 App，不再随显示名称改变。

根目录的风物匣 index.html、privacy-policy.html、terms-of-use.html、support.html、styles.css、.nojekyll 和原 README.md 保持原状。不要改仓库名称、Pages 发布分支/目录、域名或旧页面路径，不对根首页设置跳转。未来若需要多 App 导航页，新增 apps/index.html，不得替换根首页。

政策更新前核对实际发行版本的数据流、权限、SDK、缓存和删除能力，保留署名与 CC BY-SA 4.0 说明。当前文本依据 2026-10-02 工作区源码编写，开发者仍需在 Xcode/设备中确认运行行为及商店隐私申报。
